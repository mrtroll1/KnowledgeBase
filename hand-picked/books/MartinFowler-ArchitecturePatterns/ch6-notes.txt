	'If you have a lot of users, you’ll want to consider clustering to improve your throughput. In this case you’ll want to think about whether you need session migration. Session migration allows a session to move from server to server as one server handles one request and other servers take on the others. Its opposite is server affinity, which forces one server to handle all requests for a particular session. Server migration leads to a better balancing of your serv- ers, particularly if your sessions are long. However, that can be awkward if you’re using Server Session State (458) because often only the machine that handles the session can easily find that state.There are ways around that— ways that blur the lines between Database Session State (462) and Server Ses- sion State (458).'
