## Repo Structure

- `Books/` — Book notes organized by author and title
- `ClaudeCourses/` — Interactive courses using Claude Code as educator
- `PashaChecklists/` — Condensed reference checklists
- `agentic-insights/` — Insights captured automatically from Claude Code sessions

## Insights Directory Convention

When placing an insight in `agentic-insights/`, follow this structure:
- `agentic-insights/<topic>/strengths.md` — what the user does well
- `agentic-insights/<topic>/weaknesses.md` — what the user could improve
- Topic folders use lowercase kebab-case
- Each file has a header with: title, source project, tags
- If an insight extends an existing file on the same topic, merge into it rather than duplicating
- Keep content faithful to the original — clean up formatting but don't embellish
- You can also update other parts of this repo if this insight affects them. For example, outcome.md files could be modifed if some knowledge is demonstrated.
