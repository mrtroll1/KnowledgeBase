# JavaScript Fundamentals Course

A deep-dive course into JavaScript fundamentals, designed to be completed with Claude Code.

## Prerequisites

- Basic programming knowledge (variables, functions, loops)
- A browser with DevTools (Chrome recommended)
- Node.js installed (for running snippets outside the browser)

## Lessons

| # | Topic | Focus |
|---|-------|-------|
| 01 | [Prototypes](lessons/01-prototypes/lesson.md) | [[Prototype]] chain, constructor functions, ES6 classes as sugar |
| 02 | [Context & `this`](lessons/02-context-and-this/lesson.md) | Call-site rules, the 4 binding rules, arrow functions |
| 03 | [Async JavaScript](lessons/03-async/lesson.md) | Event loop, callbacks, Promises, async/await |
| 04 | [ES6+ Features](lessons/04-es6-plus/lesson.md) | let/const, destructuring, spread/rest, optional chaining |
| 05 | [DOM Manipulation](lessons/05-dom/lesson.md) | Querying, mutations, rendering pipeline, performance |

## How to Use

1. Read the lesson (`lesson.md`)
2. Try the code snippets in your browser console or Node.js
3. Take the quiz (`quiz.md`) — try answering before looking at the answers
4. Check your answers (`answers.md`) — focus on understanding *why*
5. Review your progress in `outcome.md`
