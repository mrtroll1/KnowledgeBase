# Lesson 7 Quiz: Equifax & WannaCry — Unpatched Systems

Answer these questions without looking back at the lesson. The goal is to check whether you understand the concepts, not whether you memorized dates.

---

### Question 1: The Timeline Gap

Both WannaCry and the Equifax breach exploited vulnerabilities that already had patches available. Explain what the "danger zone" is in vulnerability management. Why does this gap exist in large organizations, and what makes it so difficult to close?

---

### Question 2: Zero-Day vs. N-Day

What is the difference between a zero-day vulnerability and an n-day vulnerability? Which type was used in the WannaCry and Equifax attacks? Which type do you think is responsible for more real-world breaches, and why?

---

### Question 3: Automated Patching

A developer says: "I run `npm install` when I start a project and never touch dependencies again. If it's not broken, don't fix it."

Explain why this approach is dangerous. Describe at least two automated tools or practices that would address this problem, and explain what each one does.

---

### Question 4: Defense in Depth

Even if Equifax had failed to patch Apache Struts, the breach did not have to result in 147 million stolen records. Describe at least three additional security measures (defense in depth) that could have limited the damage, and explain how each one would have helped.
