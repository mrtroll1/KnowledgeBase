# Lesson 1: Semantic HTML — Quiz

## Q1
What's wrong with this markup? How would you fix it?

```html
<div class="header">
  <div class="nav">
    <div><a href="/">Home</a></div>
    <div><a href="/products">Products</a></div>
    <div><a href="/contact">Contact</a></div>
  </div>
</div>
<div class="main">
  <div class="article">
    <h3>Welcome to Our Store</h3>
    <div class="text">We sell quality products...</div>
  </div>
</div>
```
