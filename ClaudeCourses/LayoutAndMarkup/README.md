A web layout and markup course to complete with Claude Code.

## Prerequisites

Tools to have installed:
 - claude
 - A modern browser (Chrome, Firefox, or Safari) with DevTools
 - A code editor with HTML/CSS support

## Lessons

### Lesson 01 — Semantic HTML
Native HTML done right. Why semantic tags exist, how they improve accessibility and SEO, and how to replace div soup with meaningful markup.

### Lesson 02 — CSS Specificity
Understanding the cascade. How browsers decide which styles win, the specificity scoring system, and guidelines for writing maintainable selectors.

### Lesson 03 — BEM Methodology
Block, Element, Modifier — a naming convention that keeps CSS predictable. How to identify blocks, name elements, apply modifiers, and pair BEM with flat specificity.

### Lesson 04 — CSS Transitions & Animations
Smooth, performant motion on the web. The rendering pipeline, why transform and opacity are cheap, how to write transitions and keyframe animations, and accessibility considerations with prefers-reduced-motion.

## How to Use This Course

1. Open a lesson directory and read `lesson.md`
2. Try the code examples in your browser
3. Take the quiz in `quiz.md`
4. Check your understanding against `answers.md`
5. Ask Claude Code questions — it will track your progress in `outcome.md`
