An Object-Oriented Programming course to complete with Claude Code.

## Prerequisites

- Familiarity with at least one programming language (examples use TypeScript)
- Node.js / ts-node installed (to run examples)
- A code editor

## Course Structure

### Lesson 01 — OOP Fundamentals
Static fields & methods, encapsulation, access modifiers, getters/setters, inheritance, abstract classes, association vs aggregation vs composition, inheritance vs composition tradeoffs.

### Lesson 02 — Design Principles
DRY, KISS, YAGNI and their tensions. Full SOLID breakdown: SRP, OCP, LSP, ISP, DIP. Each principle with bad code / good code comparisons.

### Lesson 03 — Design Patterns
Publisher-Subscriber, Singleton, Factory Method, Abstract Factory, Template Method, MVC. Each pattern: problem, solution, code example, when to use.

### Lesson 04 — Relationships & Cohesion
High vs low cohesion, tight vs loose coupling, how to identify and split classes, UML basics for class diagrams, and putting it all together.

## How to Use

1. Read each lesson's `lesson.md`
2. Try the `quiz.md` without looking at answers
3. Check your reasoning against `answers.md`
4. Discuss anything unclear with Claude — it will track your progress in `outcome.md`
