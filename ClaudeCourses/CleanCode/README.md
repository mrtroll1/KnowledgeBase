A course on writing clean, maintainable code based on Robert Martin's Clean Code, to complete with Claude Code.

## Prerequisites

- Familiarity with JavaScript or TypeScript
- Some experience writing production code (any amount)
- A code editor you're comfortable in

## Lessons

1. **Naming** — Intention-revealing names, avoiding misinformation, class nouns vs method verbs
2. **Functions** — Small functions, single responsibility, argument count, no side effects
3. **Comments** — Good vs bad comments, expressing yourself in code instead
4. **Formatting** — The newspaper metaphor, vertical openness, density, distance, and ordering
5. **Objects & Data Structures** — Procedural vs OOP tradeoffs, SRP, cohesion, organizing for change

## How to Use

Open a lesson directory and read `lesson.md`. When you feel ready, try `quiz.md` without looking back. Check yourself against `answers.md`. Discuss anything unclear with Claude.
